# Support policy

## Channels

- **Security reports:** use the private route in [SECURITY.md](SECURITY.md). Never use public issues for suspected vulnerabilities or secrets.
- **Defects:** open a public [GitHub issue](https://github.com/Syntax-Circus/cmsify/issues) with a minimal, sanitized reproduction, affected version, and expected versus actual behavior.
- **Usage questions:** start a GitHub Discussion when the repository administrator has enabled Discussions; otherwise open a public issue clearly marked as a question. Do not include credentials or customer data in either channel.

## Support window and end of support

The current stable major line receives community-maintained defect triage while it is supported. Stable versions remain subject to the [API compatibility policy](docs/api-compatibility.md); security reports follow the response targets in SECURITY.md. An end-of-support notice will identify the last supported version, the final security-fix date if any, and the supported upgrade path. Until that notice is published, do not infer a hosted SLA, a guaranteed response time for ordinary defects, or support for an unreleased version.
