# Cmsify

<p class="cmsify-hero__eyebrow">COMPOSABLE CONTENT, DELIVERED</p>

Cmsify is a headless CMS for teams that need versioned content models, a dependable API, and an administration experience built for real editorial work.

## Start where you are

New to Cmsify? Follow the [local setup guide](getting-started.md) to launch the stack, sign in, and create an API client.

Building an application? Read the [API integration guide](integrating.md), then choose the [TypeScript client](sdk/typescript.md) or [.NET client](sdk/dotnet.md).

Operating Cmsify? See the [configuration reference](configuration.md) and [operations guide](operations.md).
